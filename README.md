### 개정 이력

**8/19 2차** — 상무님 "차별화가 덜 보인다" 피드백 반영
- 자체 브랜드 오너십 기반 전용 기획 협업을 독립 슬라이드로 승격 (5장 → 6장)
- 클로징에 "여러분 이름이 붙은 상품까지 같이 만들고 싶습니다" 콜백 추가
- 슬라이드 02 회사소개 압축, 03 상품 수 문장·04 외부확인 문장 삭제로 시간 확보
- 전략 섹션을 킥 3축 구조로 재구성

**8/19 1차**
- 명품 연 1,000억 직매입, 현대백화점 상품 공급
- 상무 직통 연락처 공개 연출
- 슬라이드별 시간 배분을 실측 낭독량 기준으로 재조정
- 중복 표현 정리, NCSI·KCSI 연도를 화면 배지로 이동
- 발표자 모드에서 상단 링크 숨김

### 시간 실측

원고 1,338자. 분당 250자 기준 5분 21초, 가장 느린 분당 230자에 슬라이드 전환 5회를
더해도 5분 59초. **여유가 1초뿐이라 리허설 실측이 필수입니다.**

초과 시 슬라이드 02의 회사 소개 한 문장을 먼저 뺍니다(화면으로 대체 가능).
